# smartcast-service
Умная платформа для подкастов и аудиокниг с AI-транскрибацией, интерактивными субтитрами, поисками по тексту и авто-выжимкой контекста.


## Запуск через докер

1. Убедитесь, что приложение **Docker Desktop** запущено на вашем компьютере.

2. Из корневой директории проекта выполните команду для сборки и запуска контейнеров:

   Для первой сборки и запуска всего стека одной командой:
   ```bash
   docker-compose -f docker-compose.dev.yml up --build
   ```
   
   Для последующих запусков используйте:
   ```bash
   docker-compose -f docker-compose.dev.yml up
   ```
   (Для запуска в фоновом режиме используйте флаг -d)
   
   Для запуска только одного модуля укажите его название:
   ```bash
   docker-compose -f docker-compose.dev.yml up -d <service_name>
   ```
   
   Для остановки контейнера используйте:
   ```bash
   docker compose -f docker-compose.dev.yml down
   ```
   (Используйте флаг -v, если хотите удалить тома)
